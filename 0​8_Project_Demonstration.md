# Phase 8: Project Demonstration

## Demonstration Walkthrough

1. **Step 1: High Impact Trigger**
   * Open **Incident → Create New**[cite: 1].
   * Select **Impact = 1 - High**[cite: 1].
   * *Observation:* An info banner appears stating *"Urgency set to High for High impact incident"*, and Urgency becomes read-only[cite: 1].

2. **Step 2: Save Prevention**
   * Leave **Assigned To** blank and click **Submit**[cite: 1].
   * *Observation:* Submission is prevented. An error box appears stating *"Assigned To is mandatory for High impact incidents"*[cite: 1].

3. **Step 3: Successful Save**
   * Select a user under **Assigned To** and click **Submit**[cite: 1].
   * *Observation:* The Incident is created successfully[cite: 1].

4. **Step 4: List Edit Prevention**
   * Go to **Incident → All**[cite: 1].
   * Attempt to double-click and change the **State** of an incident from the list view[cite: 1].
   * *Observation:* Alert pops up stating *"State cannot be updated using list editing. Please open the Incident"*, blocking list modification[cite: 1].
